# 铭牌编号入仓前抽查核对

档案员在铭牌编号入仓前抽查录入是否准确。Flask + SQLite 网页应用, 用 Docker Compose 启动。

## 业务规则

- **开批**: 导入批号和含唯一条目号的铭牌编号清单; 为每批设定
  - 错录率上限: 0~99 的整数百分比;
  - 1~3 个严格递增的累计抽查数(检查点)。
  系统按种子随机无放回抽出有序名单, 抽样数 = 最大累计抽查数。
  同批号重传沿用原方案, 不重新抽样(清单不一致时给出提示)。
- **录入**: 核对结果可乱序录入; 每条只记首个结果, 重复录入拒绝; 结批后停止录入。
- **判定**: 从抽样第 1 条到某检查点全部核完才判定该点。假定全批错录数为刚超限的最小整数
  `D = ⌊N × 上限%⌋ + 1`, 计算该检查点抽到不多于实测错录数的超几何概率
  `P = P(X ≤ x)`, `X ~ Hypergeometric(N, D, n)`。
  `P ≤ 5% ÷ 检查点数` 即通过。
- **结批**: 在首个通过的检查点封存放行结论(检查点、抽查数、错录数、概率);
  所有检查点核完仍未通过则标为「待全检」。
- **重录核对(结批后)**: 已结批批次可按稿号上传重录稿(纸档重录后拆份入仓),
  同稿号再次上传即整份替换。CSV 三列: 新条目号、铭牌编号、原条目号;
  新条目号稿内唯一, 原条目号可留空。
  一行同时满足「原条目核对为正确 + 铭牌编号与原条目逐字相同 +
  该原条目号在本批所有现行稿中只被引用一次」才沿用旧核对,
  其余行进入该稿的待复核清单并注明原因(留空、原条目不存在、未抽中/未核、
  旧核对为错误、铭牌不同、跨稿重复引用)。任一稿新增或替换后,
  全部现行稿按现状重新判定; 换稿失败时单事务回滚, 各稿及清单保持原状。
  每稿的待复核清单可在网页查看并下载 CSV, 下载链接带清单摘要 token:
  清单一旦变化, 旧链接暂停下载并提示刷新; 别的稿变化而本稿清单不变时仍可下载。

## 启动(Docker Compose)

```bash
docker compose up --build
# 打开 http://localhost:8000
```

SQLite 数据保存在命名卷 `nameplate-data` 中。

## 本地运行(无 Docker)

```bash
pip install -r requirements.txt
python3 wsgi.py          # 或 flask --app wsgi run
```

## 网页演示流程

1. 「开批」页: 填批号、错录率上限、累计抽查数、清单(可点「填入演示数据」一键填充), 提交后生成有序抽样名单。
2. 批次详情页: 按名单核对并逐条录入「正确/错误」(可乱序); 演示辅助按钮可把当前检查点未核条目批量提交。
3. 每核完一个检查点的前缀即自动判定; 通过后封存「放行」结论, 全部未通过则标「待全检」。
4. 「批次查询」页查看所有批次状态与封存结论。
5. 结批后批次详情页出现「重录核对」区, 可演示完整换稿流程:
   - 点「填入演示稿 G1」再上传, 查看 G1 的待复核行(铭牌不同、原条目留空等)与沿用行;
   - 点「填入演示稿 G2(与 G1 重复引用)」再上传, 见两稿同一原条目均因「引用 2 次」转入待复核;
   - 点每稿的「下载待复核清单 CSV」, 内容与页面逐行一致; 清单变化后再用旧链接下载, 会暂停并提示刷新;
   - 点「生成 G2 替换稿(去掉重复引用)」再上传(整份替换), 见 G1 自动恢复沿用;
   - 上传一份稿内新条目号重复的非法稿, 提交后报错且现稿版本、行数与清单保持原状。

## JSON API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/batches` | 开批 `{batch_no, limit_pct, checkpoints[], items[{entry_no,nameplate_no}], seed?}`; 同批号返回 200 且 `created=false` |
| GET | `/api/batches` | 批次列表 |
| GET | `/api/batches/<批号>` | 详情: 方案、有序抽样名单、检查点进度、判定记录、封存结论、各重录稿待复核清单 |
| POST | `/api/batches/<批号>/results` | 录入 `{entry_no, result: "ok"\|"err"}`; 返回本次触发的判定 |
| POST | `/api/batches/<批号>/rekey/drafts` | 上传/整份替换重录稿 `{draft_no, csv_text}`; 返回该稿现行待复核清单与 `token` |
| GET | `/api/batches/<批号>/rekey/drafts` | 全部现行稿及其待复核清单、沿用行数、token |
| GET | `/api/batches/<批号>/rekey/drafts/<稿号>` | 单稿现行判定 |
| GET | `/api/batches/<批号>/rekey/drafts/<稿号>/download?token=` | 下载待复核 CSV; token 与现行清单不符返回 409(网页路由改为重定向回详情页提示刷新) |
